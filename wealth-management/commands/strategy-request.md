Load the `strategy-request` skill and `strategic-library` skill. Assemble a complete SOA Summary Request in the standard template format with all mandatory sections (Entities, Summary of Advice, Alternatives, Product Considerations, Projection Parameters, TMD, Notes, Change Log). Output is CRM-ready. Follow all house style rules from CONVENTIONS.md.

Run analytical skills first (financial-plan, debt-recycling, super-strategy, etc.) if the strategy analysis has not yet been completed. The Strategy Request assembles their outputs into the template.

If a client name is provided, use it. Otherwise ask for client details.
